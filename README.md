## 📌 Featured Projects

### 🔐 BioLock: Biometric Bike Security with Engine Lock and Tire Immobilizer
*Major Project*

An ESP32-based security system that allows access only after fingerprint verification using an R307 sensor. Unauthorized attempts trigger SMS alerts to the owner through a SIM900 GSM module. A relay locks the engine and a servo motor immobilizes the tire. System status is shown on an LCD, and the Blynk IoT platform enables remote monitoring.

**Technologies:** ESP32 • Embedded C • R307 Fingerprint Sensor • SIM900 GSM • Servo Motor • Relay • LCD • Blynk IoT

### 🏍️ Bike Security System using Arduino UNO and GSM
*Mini Project*

A theft-detection system built with Arduino UNO and a SIM900 GSM module that sends SMS alerts to the vehicle owner.

**Technologies:** Arduino UNO • Embedded C • SIM900 GSM
